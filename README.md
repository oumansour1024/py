# Learning Pandas Libary

## Overview
In That project you  will see  how  useing libary pandas in project python


## Installation
1. Create and activate a virtual environment:
   - Windows (PowerShell): `python -m venv .venv` then `.\.venv\Scripts\Activate.ps1`
   - macOS/Linux: `python3 -m venv .venv` then `source .venv/bin/activate`
2. Install pandas:
   - `pip install pandas`
3. (Optional) Install Jupyter Notebook for working with notebooks:
   - `pip install jupyter`

## How to Run
1. Activate virtual environment: `source .venv/bin/activate`
2. Launch Jupyter: `jupyter notebook`
3. Open `01_exploration.ipynb`
